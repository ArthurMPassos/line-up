# Lineup

A pass-and-play number-ordering party game for one phone, in English and Portuguese.

**Play:** https://arthurmpassos.github.io/line-up/

## How to play

1. Everyone secretly gets a number from 1 to 100. Pass the phone around to see yours.
2. Describe your number using the theme, without saying it.
3. Drag the face-down cards into order, lowest at the top.
4. When you agree, flip them one by one.

Comes with 152 themes (or write your own). Everything is in a single `index.html` with no dependencies.
